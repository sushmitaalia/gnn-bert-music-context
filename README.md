# GNN-BERT Music Context Understanding

Course Project for CSE425 Neural Networks.

## Project Goal

The goal of this project is to build a hybrid GNN + BERT model for understanding musical context.

- BERT will process textual information such as music tags, captions, or lyrics.
- GNN will process structural relationships in music represented as graphs.
- A fusion model will combine both representations to predict musical context such as genre, mood, and tags.

## Project Structure

- `data/raw/` - raw datasets
- `data/processed/` - processed audio features and graph data
- `data/splits/` - train, validation, and test splits
- `notebooks/` - exploratory analysis and demo notebooks
- `src/` - source code
- `results/` - metrics, plots, and experiment outputs
- `report/` - final project report
